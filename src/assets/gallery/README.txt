Drop your photos in this folder.

Supported: .jpg .jpeg .png .webp .avif

They show up on the website automatically after you refresh.

Rename anytime. The file name becomes the caption, and the first word can set the category.

Examples:
  01-camp-evening.jpg          -> Camp . "Camp evening"
  02-tents-alpine.jpg          -> Tents . "Tents alpine"
  03-stage-night.jpg           -> Stage . "Stage night"
  04-food-angami-kitchen.jpg   -> Food . "Food angami kitchen"

Category words you can start a file name with:
  camp  tents  tent  stay  village  festival  food  stage  artist  crowd  music

Anything else falls back to the Camp category.

Use 01-, 02-, 03- at the start if you want a specific order.

Hyphens, underscores, spaces and dots all work as separators, so both
"03-artist-soulmate.jpg" and "03. Artist.jpg" are read correctly.

Two photos in the Stage category are used outside the gallery: the first one
appears in the About section, the second in the Festival band.
